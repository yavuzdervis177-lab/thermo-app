# IsoPro – App für Thermo Dämmtechnik GmbH

Aufmaß, Isometrie, Stundennachweis und Projektdokumentation für Wärme-, Kälte-, Schall- und Brandschutz.

**App öffnen:** https://yavuzdervis177-lab.github.io/thermo-app/

Installation auf dem Handy: Adresse in Chrome öffnen → ⋮ → „App installieren“.
Die Daten werden nur auf dem jeweiligen Handy gespeichert (Übertragung über ⚙ → Datensicherung).
